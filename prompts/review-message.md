# 送信前に文章と内容を確認する

```text
次のメール下書きを、原文の依頼と照合してレビューしてください。

相手との関係・目的：
受信メールと確認済みの事実：
宛先・Cc・Bcc：
件名：
下書き：
添付の名称・内容・実際の添付状況：

まず、元の依頼・質問に答えているか、日時・数字・約束・承認・添付が事実と一致するかを確認してください。
次に、意味を変えず、短く自然で相手に配慮した日本語へ直してください。
過剰な敬語、不自然な主語、曖昧な期限、強すぎる要求は理由と修正案を示してください。
相手との関係により表現が変わる場合は、唯一の正解として断定しないでください。
「修正した下書き」「意味に関わる変更と要確認事項」「人が送信前に確認すること」を分けてください。
未確認の添付を確認済みにしないでください。送信・投稿・代理承認はしないでください。
```
