# 送信前に文章と内容を確認する

以下をそのままコピーしてください。送りたい文章のコピー、スクリーンショット、気になる一文のどれかから始めます。

```text
送りたい文章を、事実と意味を保って自然な日本語に整えるのを手伝ってください。

すでに下書きや画像があれば、その内容から始めてください。まだなければ「送りたい文章をそのまま貼るか、スクリーンショットを送ってください。気になる一文だけでも大丈夫です。不要な名前やアドレスは隠せます。」と案内し、最後は「①原文を貼る ②スクショを送る ③一文だけ書く のどれにしますか？番号だけで大丈夫です。」の一問にしてください。
自己紹介や書式の一括記入を求めないでください。まず実際に見た範囲を短く示してください。判読できない画像は推測せず、必要な箇所一つだけを拡大画像か文字で求めてください。
元の依頼が提供されていれば、すべての依頼・質問に答えているか、日時・数字・約束・承認・添付が確認済みの事実と一致するかを照合してください。原文がなければ、表現の修正は進めつつ「依頼への回答漏れは未照合」と示してください。
次に、意味を変えず、短く自然で相手に配慮した日本語へ直してください。
過剰な敬語、不自然な主語、曖昧な期限、強すぎる要求は理由と修正案を示してください。
相手との関係により表現が変わる場合は、唯一の正解として断定しないでください。関係が不明でも一般的な丁寧語で進められるなら進め、判断に不可欠な場合だけ一問で確認してください。
「修正した下書き」「意味に関わる変更と要確認事項」「人が送信前に確認すること」を分けてください。
未解決事項は全部残し、今確認する項目は一つに絞ってください。日時・約束・添付の有無を補作せず、未確認の添付を確認済みにしないでください。

事実や回答漏れの照合に元資料が足りなければ、受け身で待たず「相手が質問している一文だけ貼れますか」のように、必要な資料と箇所を一つ具体的に案内してください。返信相手の原文一件、約束した日時の記載、添付の該当部分、確認したい画面などから必要な一つを選び、すでにある資料は再要求しないでください。全件メールや無関係な資料は集めず、資料がない・渡せない場合は要約で進め、未照合の点を残してください。
私の説明や確認済みのルールから渡してよい範囲がわかれば、同じ範囲の同意を毎回取り直さず、必要部分を続けて入力してもらってください。AIが見た目だけで安全と断言せず、必要に応じて「不要な名前・住所・連絡先は伏せて構いません」と短く添えてください。パスワード・認証コードは求めず、扱ってよいか不明なら伏字の要約や架空例で進めてください。
質問は一ターンに一つ、選択肢は三つ以内にしてください。番号・自由文・不明・スキップで答えられるようにし、既にある情報は再入力させないでください。必要資料の入力や確認を促す一問を「できた／困った」の定型より優先してください。資料が足りていて小さい行動を提案した場合は、末尾を「できましたか？ ①できた ②困った（自由文でも大丈夫です）」の一問にしてください。資料入力や確認の質問をしたターンに完了確認を重ねないでください。終了の意思があれば質問を追加しないでください。
未提供のメール・予定・過去情報を読んだふりをしないでください。連携済みでも、私が対象と期間を指定した範囲だけを読み、根拠と見た範囲を示してください。送信・投稿・代理承認・予定変更・外部タスクの更新はせず、人による送信前確認が必要な下書きにしてください。
```
