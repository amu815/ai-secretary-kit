# 毎日の使い方

最初の設定がまだなら、[Webガイド](https://ai-secretary-kit-amu815.easytoast2050.chatgpt.site)または[はじめ方](quickstart.md)の文をChatGPTアプリへそのまま送ります。使う場面やAIへの慣れ具合の質問は任意です。実名や所属は不要で、用事をすでに渡した場合は自己紹介を繰り返さず、その内容から進めます。

普段は同じチャットに、次のいずれかを渡してください。先に空欄フォームを埋める必要はありません。

- 全体の仕事・学業・暮らしのリストを、コピーして貼る。
- 手帳やアプリの画面のスクリーンショットを渡す。
- 一覧がなければ、気になる用事を1件だけ書く。

業務情報を渡してよいか所属先のルールを確認し、画像に映る無関係な名前や通知は除きます。画像の読めない部分や不足情報は、必要なところだけ一問ずつ確認します。すでに渡した内容を聞かれたら「上の内容から進めてください」と伝えます。

## 朝：今日の容量と次の一手を決める

最新のリストや画像を渡し、「今日の順番を決めたい」と伝えます。一覧がなければ、思い出せる1件からで構いません。対応できる時間や固定予定など、判断に必要な不足は会話で一つずつ補います。専用の文を使いたい場合は、Webガイドの場面別メニューや[朝の整理](../prompts/daily-plan.md)の文をそのまま送れます。

締切だけでなく、確認者の待ち時間、作業量、遅れた場合の影響も見ます。たとえば、来週提出でも別の人の確認に数日かかる仕事は、今日始める必要があります。逆に、「至急」という言葉があっても日時と影響が不明なら確認を挟みます。

出力は「まず一つ」「その次」「待ち」「相談」に分けます。同時に多くの作業を開くことを目標にせず、全体を見ながら一つずつ進めます。予定が時間内に収まらなければ、期限・担当・範囲の調整案を作ります。

最後の一問には「できた」「困った」などで答えます。「困った」なら手順を一段小さくしてもらいます。質問がいくつも並んだら「次の一問だけ聞いてください」と伝えてください。「今日はここまで」と伝えたら、追加の質問をせず終えるようにしています。

## 依頼が来たら：読み取りと返信を分ける

1. 入力してよいメール本文や画像を渡し、「用件を整理したい」と伝える。[メール読解](../prompts/read-email.md)の文を使ってもよい。
2. 原文と照合し、曖昧な期限や見られない添付を確認する。
3. 最新のタスク表と合わせ、今日の順番を更新する。
4. 返信が必要なら下書きを作り、[文章確認](../prompts/review-message.md)に通す。
5. [送信前チェック](../templates/send-checklist.md)を人が行い、自分で送信する。

長いスレッドの途中で依頼が取り消されたり、期限が変わったりする場合があります。最後のメールだけで判断せず、確認できた範囲を明示してもらいます。全文を渡していない場合は「全文確認済み」と扱いません。

メールの原文や添付を渡していないのに、読んだように回答した場合は「実際に確認した原文と見ていない範囲を分けてください」と伝えます。連携がある場合も、対象・期間と、実際に読めた範囲を確認します。

## 共有の仕事：候補から担当確定までを残す

普段の共有メモや予定表に、未割当の仕事も記録します。必要なら[共有タスク表](../templates/task-board.md)も使えます。「誰かがやるはず」のままにせず、次の状態を区別します。

```text
未割当 → 引受候補あり → 本人が引受 → 着手 → 確認待ち → 完了
```

候補をAIが提案しても、本人の引受確認までは担当確定にしません。「見ました」という受領と、「私が対応します」という引受は区別します。共同編集ができない表では、引受を連絡し、まとめ役が確定します。競合したら作業を始める前に一本化します。

一人が多く引き受け続けないよう、件数に加えて所要時間、難しさ、固定業務も見ます。誰の成績がよいかというランキングには使いません。

## 終業・不在前：共有と引受を分ける

最新のリストや用事を渡し、「不在前の引き継ぎを整理したい」と伝えます。期限、なぜ急ぐか、次の行動、必要な資料などの不足を一問ずつ確認し、下書きを作ります。専用の[引き継ぎ用の文](../prompts/prepare-handoff.md)や、整理結果を残す[引き継ぎ票](../templates/handoff.md)も使えます。

相手から引受の返事がない場合は、事前に決めた相談先に確認します。AIに「引き継いだ」と伝えただけでは、相手への通知や合意は成立しません。

## コピーが負担になったら：連携は任意で追加する

GmailやGoogle Calendarから何度も情報をコピーする負担が出てきたら、[連携の設定手順](setup-connections.md)を検討します。未連携でも上の3つの入口で使えます。

連携の設定、アクセス権限、常時監視は別のものです。許可画面を無条件に承認せず、本人がアカウントと許可する範囲を確認して操作します。基本は指定範囲の読み取りと下書きで、送信は人が行います。連携したことだけを理由に、AIがすべての依頼を読んだ・常に監視していると扱わないでください。

未連携なら追加の依頼・変更・完了を自分でチャットに伝えます。新しいチャットでは導入文と最新の材料を渡し直し、決まったことは普段の共有記録にも残します。

## 一週間ごと：運用を少し直す

振り返るのは、期限不明の仕事が減ったか、未割当が放置されていないか、返信に質問への答えが揃っているか、引き継ぎ先の引受が確認できたか、という仕事の状態です。効果は利用環境により異なり、このキットで改善率を実証したわけではありません。
