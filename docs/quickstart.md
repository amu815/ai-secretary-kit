# はじめ方：自分のAI秘書を用意する

必要なものは、ChatGPTを開ける端末と、最初に練習するための架空の予定だけです。基本手順ではGit、Python、APIキーは不要です。

## 1. 利用環境を確認する

継続して使うなら、ChatGPT Plusを導入候補にします。公式の料金案内では月額20米ドルと表示されていますが、実際の請求額・通貨・税・購入経路・利用上限は契約画面で確認してください。既に所属先から利用環境が提供されている場合は、まずそちらを確認します。[公式料金](https://learn.chatgpt.com/docs/pricing)

ChatGPTにログインし、アカウントのプラン管理・アップグレード画面でPlusの条件を確認して契約します。画面名は環境によって変わります。

この教材のコピー＆ペーストは、利用できるチャット環境から試せます。課金自体が優先順位や文章の正しさを保証するわけではありません。まず練習例で役立つかを確認してください。

## 2. 「自分のAI秘書」というプロジェクトを作る

ChatGPTのProjectsで新しいプロジェクトを作り、名前を「自分のAI秘書」にします。プロジェクトの指示欄に[共通指示](../prompts/secretary-instructions.md)の本文を貼り付けます。プロジェクトでは関連する会話や指示をまとめられます。[公式のProjects案内](https://learn.chatgpt.com/docs/projects)

指示欄やProjectsが見当たらなければ、新しい通常チャットの最初のメッセージに共通指示を貼り付けて始めます。新しいチャットに移るときは、必要な指示と最新のタスク表を渡し直してください。

初回はメールやカレンダーを接続せず、手入力で始めます。「指示を保存した」だけでは、受信箱の監視、通知、リマインダーは始まりません。

## 3. 架空の予定で練習する

[最初の練習](../examples/first-day.md)の「入力する内容」をコピーし、チャットに送ります。

AIの回答を、同じページの「確認すること」と照合します。日時や担当が勝手に補われたら、元の情報に戻して修正を求めます。メールは、依頼が全部取り出されているかを原文と見比べます。

## 4. 自分用のルールを決める

次の欄を埋め、共通指示に追記してください。不明な欄は「未定」で構いません。

```text
私が対応できる時間帯：
今日の会議・授業・家事などの固定予定：
使うタイムゾーン：Asia/Tokyo
優先順位に迷った場合の相談先：
期限に間に合わない場合の相談方法：
共有タスクを引き受けたときの記録場所：
メールの署名と、よく使う相手との関係：
AIに入力してよい情報の範囲：
```

期限が重なるときは、自分一人で処理順を変えるだけでは解決しないことがあります。AIに調整案を作ってもらい、権限のある人と期限や分担を決めます。

## 5. 毎日の運用を始める

[毎日の使い方](daily-workflow.md)に沿って、朝に整理、新しい依頼が来たら見直し、終業・不在前に引き継ぎを確認します。共有のタスク表を正本にし、AIの回答だけに進捗を残さないようにします。

必要に応じて、対応環境に[skillsを導入](install-skills.md)できます。基本手順は共通指示と場面別プロンプトだけで始められます。

## 入力する情報について

名前の置換だけでは、日時・案件名・組み合わせから相手がわかる場合があります。初回はこのリポジトリの架空データを使い、実務では必要な部分だけに絞ります。所属先の許可がない情報を、個人契約のAIへ貼り付けないでください。

実データをローカルで扱う場合は、Git管理外の場所を使います。このリポジトリ内なら `.private/` を除外設定していますが、誤って公開しない保証にはなりません。GitHubのIssueやスクリーンショットにも実データを入れないでください。
