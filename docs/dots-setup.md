# dotsを使う場合

確認日：2026-10-22。機能と利用条件は変更されるため、契約前に公式ページと自分のアカウントの表示を確認してください。

## 1. 利用条件を確認する

公式の対象一覧は、Pro 100・200・500、Business Premium、Enterpriseです。個人Proには年齢・地域条件があり、Enterpriseは管理者による有効化が必要です。段階展開のため、対象プランでもまだ表示されない場合があります。**Plusはこの対象一覧に記載されていません。** [公式のAccess](https://learn.chatgpt.com/docs/dots#access)

使えない場合も、[ChatGPTに貼り付ける基本手順](quickstart.md)を使えます。このキットを試すためだけに上位プランへ変更する必要はありません。

## 2. dotを作り、担当範囲を伝える

ChatGPTのモバイルアプリ、デスクトップアプリ、デスクトップブラウザで、利用可能になっているdotsの作成画面を開き、名前を付けます。最初はプラグインの接続を後回しにし、[共通指示](../prompts/secretary-instructions.md)を会話で渡してください。モバイルWebは対象外です。[公式のGetting started](https://learn.chatgpt.com/docs/dots/getting-started)

続けて次のように依頼します。

```text
私の用事を整理する担当になってください。
最初は、私が渡すタスク表とメールの抜粋だけを使ってください。
優先順位とその理由、確認が必要なこと、返信や引き継ぎの下書きを作ってください。
メール送信、外部への投稿、予定の変更、代理承認は私自身が行います。
今は定期実行を設定せず、この練習データを一度だけ処理してください。
```

## 3. 外部への操作を自分に引き渡す

デスクトップ／Webでは **Settings → Personalization → Permissions → Custom rules**、モバイルでは **サイドバー → Customize → Custom rules** を開きます。新しいルールに「メール送信・外部投稿・予定変更・代理承認」を記載し、**Hand off to you** を選びます。このキットでは、最後の操作は本人が行います。[公式のControls](https://learn.chatgpt.com/docs/dots/controls)

Custom rulesはAIが従おうとする指示であり、誤りが起きない保証ではありません。アプリへの接続権限は別に確認します。職場の設定でCustom rulesが無効なら、管理者のルールに従い、接続なしの運用を選びます。

## 4. 必要な情報だけ接続する

手入力で練習できたら、必要に応じてメールやカレンダーを接続します。利用する連携で読み取りと送信の権限を分けられる場合は、必要な読み取りだけを許可します。分離できない場合は、手入力・コピー運用を続ける選択肢があります。ブラウザやPC操作でも送信できる環境は、メールAPIの送信権限を外すだけでは制限しきれません。[公式のComputers and apps](https://learn.chatgpt.com/docs/dots/computers-and-apps)

このリポジトリのSKILL.mdをGitHubで公開しただけでは、dotへのインストールや適用は完了しません。ローカルskillsを使うには、[導入手順](install-skills.md)に加えてPC接続が必要で、そのPCがオンラインかつChatGPTアプリが開いている必要があります。会話に共通指示を貼る方法と、正式なskill導入は別です。

## 5. 継続運用は、一回の確認ができてから

朝の確認を定期化する場合は、時刻・タイムゾーン・読む情報・通知先・終了条件を指定し、実際にスケジュールが作られたか画面で確認します。「毎朝見ておいて」と伝えるだけで設定が完了したと決めつけないでください。

不要になったときは、定期実行と実行中の各タスクをそれぞれ確認します。dotの一時停止だけでは、委譲されたタスクや将来の定期実行がすべて止まるわけではありません。[公式の停止方法](https://learn.chatgpt.com/docs/dots/controls#stop-work)

データ設定はChatGPTの設定を確認し、組織の情報取扱基準と合わせて決めます。個人契約と組織契約、APIの条件を混同しないでください。
