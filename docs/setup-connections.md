# アプリの準備と、必要になってからのGoogle連携

最初は「教材をコピー → ChatGPTアプリのWorkに貼り付けて送る」から始めます。モデルはGPT-6 Sol、effortはMediumをキットのおすすめにしています。GmailやGoogleカレンダーの連携は、コピーする手間を減らしたくなってから試す任意の設定です。このWebサイトにアカウントやパスワードを入力する操作はありません。

## 1. ChatGPTアプリを用意する

既にアプリにログインできている方は、手順3から確認してください。

1. PCでは[OpenAI公式の導入案内](https://learn.chatgpt.com/docs/quickstart)からOSに合うアプリを入れます。スマートフォンでは端末のアプリストアで「ChatGPT」を探し、提供元がOpenAIであることを確認します。
2. アプリアイコンから開き、自分のChatGPTアカウントでログインします。パスワードや確認コードは、正規のログイン画面だけに入力します。AIとの会話やこのサイトへ貼り付ける必要はありません。
3. 新しい会話を開き、**ChatGPT → Work** を選びます。
4. 入力欄の下のモデル・推論の設定から **Advanced** を開き、**GPT-6 Sol（表示例：6 Sol）・Medium** を選びます。設定画面や選べる項目は環境で異なります。[画像付きのモデル設定手順](model-setup.md)を確認してください。
5. [Webガイド](https://ai-secretary-kit-amu815.easytoast2050.chatgpt.site)の「はじめるための文をコピー」を押し、アプリの入力欄に貼り付けて送信します。

GPT-6 SolはChatでは利用できません。見つからないときは、Workを選んでいるか、利用アカウント、アプリの更新を確認します。モデル設定は接続や権限とは別で、文を送っただけでは切り替わりません。[公式のモデル案内](https://learn.chatgpt.com/docs/models)

**できた目印：** AIから短い質問と選択肢が返ってきます。番号や短い言葉で一つ答えれば進めます。「わからない」「あとで」でも構いません。

### 権限の確認が出たら

権限は、今使いたい機能に必要なものを内容を読んで選びます。文章を貼る練習のために、マイク・通知・PC操作などの許可をまとめて有効にする必要はありません。画像を渡すときは、その画像を選ぶ操作に進みます。画面の意味がわからなければ、いったん取り消して文章一件から始められます。

PCのWebボタンでは、ブラウザの「ChatGPTを開きますか？」が出る場合があります。アプリ名を確認して開きます。ボタンで開かなくても、アプリアイコンから続けられます。スマホの自動起動を保証する機能はありません。

## 2. 用事の一覧を渡す

「今日の順番を決める」の文を、そのままアプリに送ります。AIに選択肢が出たら、できる方法を選んでください。

- **一覧がある：** チーム全体の仕事が集まった共有メモ、学校の課題一覧、家族の用事のメモなどを、そのままコピーして貼ります。自分の担当だけに絞らず、担当が決まっていない項目も残すと、全体を整理できます。
- **画面にある：** スクリーンショットを撮り、必要な部分だけ切り取ります。ChatGPTの画像を追加する操作（＋など）から選んで送ります。文字が小さければ、必要な箇所を拡大した画像にします。
- **一覧がない：** 「人数を知らせる」「提出するものがある」など、気になっている用事を一つだけ書きます。

仕事や家族の情報は、AIへ渡してよい範囲を先に確認します。不要な名前、メールアドレス、住所、顔写真などは隠してください。名前を隠しただけで匿名になるとは限りません。まだ判断できない場合は、Webガイドの架空の練習を使えます。

**できた目印：** AIが「貼られたメモ」など読めた資料を示し、暫定の優先順位表と次の一件を提案します。不足があれば「Aの依頼メールを1件」「締切の箇所の画像」など、今必要な資料一つを案内します。共有してよい範囲だけを渡し、不明なら名前などを伏せた要約や架空例で進めます。資料を求めた回には、完了の質問を重ねないようにしています。見えない予定や未接続のメールを読んだと言ったら、次を送ります。

```text
今回渡した資料だけを使ってください。まだ渡していない予定やメールを見た扱いにせず、次に必要なことを一つだけ、短い例を付けて聞いてください。
```

## 3. 任意：まずGoogleカレンダーをつなぐ

仕事・学校のGoogleアカウントは、所属先の利用ルールと管理者の許可を確認してから進めます。ここでは予定を**見るだけ**の確認から始めます。これは本キットの運用手順であり、接続機能の権限を技術的に制限する設定ではありません。

1. ChatGPTの **Plugins（プラグイン）** を開きます。環境によって **Apps** と表示される場合もあります。
2. **Google Calendar** を検索し、詳細で提供元・使える機能・接続先を確認します。詳細の **＋ / Install** などから追加し、**Connect** などの接続案内に進みます。表示名は環境で異なります。[公式のプラグイン手順](https://learn.chatgpt.com/docs/plugins)
3. Googleの認証画面では、連携したいアカウントのメールアドレス、接続先のアプリ名、要求されるアクセス権を読みます。閲覧だけか、予定の作成・変更・削除も可能かを確認します。必要性がわからない権限があれば、許可せず戻って構いません。
4. 接続後、ChatGPTの **Work** で新しい会話を開き、入力欄で **@** を入力して **Google Calendar** を選びます。見つからなければ無理に続けず、手動で予定を貼る方法に戻ります。
5. 下の文を送ります。AIが尋ねた日を答え、必要な場合はタイムゾーンも一問ずつ確認します。表示された予定と、実際のGoogleカレンダーを見比べます。

```text
Googleカレンダーの接続を確認したいです。まだ予定を検索せず、まず「どの日の予定を見ますか？ ①今日 ②明日 ③日付を書く」と一問だけ聞いてください。
日付の基準やタイムゾーンが不明なら、一問ずつ確認してから、その一日だけを調べてください。
読み取ったカレンダー名・対象日・予定の時刻・根拠リンクを、取得できた範囲で示してください。リンクが得られなければ作らず、得られなかったと書いてください。
予定の作成・変更・削除、招待の送信はしないでください。接続できない場合や予定が見つからない場合は、そのまま伝えてください。
```

**できた目印：** 対象の日と取得元がわかり、元のカレンダーと内容が一致します。「接続できない」と出た場合も、予定を推測で補わせないでください。

## 4. 任意：Gmailも一件だけ試す

GmailはGoogleカレンダーと別に接続します。Plugins／Appsで **Gmail** を探し、同じ流れで追加・接続します。Google側のアカウントと権限をもう一度確認してください。「メールの管理」などの権限には、単なる閲覧以上の操作が含まれる場合があります。[Google公式のアクセス権の説明](https://support.google.com/accounts/answer/14012355?hl=ja)

新しいWorkの会話で **@** から **Gmail** を選び、次を送ります。

```text
Gmailの接続を一件だけ確認したいです。まだ検索せず、まず「探したいメールの件名の一部か、送信者を一つ書けますか？」とだけ聞いてください。
その後、検索する期間を一問で確認してください。指定された対象と期間だけを検索し、最大一件の件名・送信日時・元メールへのリンクを、取得できた範囲で示してください。
本文を開く必要があれば先に確認してください。送信・転送・返信・下書き保存・削除・既読変更はしないでください。見つからない場合や接続できない場合は、そのまま伝えてください。
```

**できた目印：** 本人が探したかった一件と、表示されたメールが一致します。検索の一件が確認できたら、次から「この送信者の今週の依頼」など、必要な範囲を指定して整理に使えます。受信箱全体を毎回読ませる必要はありません。

GmailやGoogleカレンダーの使える機能は、プラン・地域・所属先の設定などで変わります。公式チュートリアルにはメール検索や予定確認の例がありますが、全員に同じ機能や画面が提供される保証ではありません。[OpenAI公式チュートリアル](https://developers.openai.com/training/walkthroughs/plugins-and-skills)

## 5. 見つからない・許可できないとき

- **スマホで入口が見つからない：** PC版のPlugins／Appsで確認します。それでも見つからなければ、コピーや画像で続けます。
- **Disabled by admin / Admin approval required：** 所属先の管理者に確認します。制限を回避するために業務情報を個人アカウントへ移しません。
- **Google側でブロックされる：** 組織の外部アプリ制限の可能性があります。[Google公式のエラー案内](https://support.google.com/accounts/answer/16668185?hl=ja)を確認します。
- **「すべて許可」してよいかわからない：** いったん取り消します。必要な権限を個別に選べるかは、実際の画面で確認してください。本教材は全権限の一括承認を勧めません。

「接続した」「検索できた」「同期できた」は同じ意味ではありません。同期対応や対象範囲は各プラグインの詳細を確認します。接続しただけで、すべてのメールや予定が常に最新の状態で読まれたり、締切の自動通知が始まったりするとは限りません。

## 6. 連携をやめるとき

Googleアカウントの接続管理で、対象アプリの **Googleアカウントへのアクセス** を確認し、詳細からアクセス権を削除します。表示名が異なる場合は[Google公式の接続管理手順](https://support.google.com/accounts/answer/13533235?hl=ja)を参照してください。

ChatGPTのプラグイン削除と、接続先サービスの認証解除は別の場合があります。プラグインを消しただけで解除できたと判断せず、Google側でも状態を確認します。アクセス権を取り消しても、過去に共有済みのデータがすべて自動削除されるとは限りません。
