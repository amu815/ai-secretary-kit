# 最初の練習：架空の予定

以下はすべて架空の教材です。実在する職場・学校・家庭の事例ではありません。

## 入力する内容

```text
現在は2030年6月10日09:00、Asia/Tokyoです。
今日は09:00〜12:00、13:00〜16:00に対応できます。
10:00〜11:00は固定の予定があります。
明日は対応できません。優先順位の相談先は窓口係です。

A. イベントの出欠人数を今日11:30までに知らせる。集計には30分。
   連絡が遅れると会場の席数が決められない。自分が担当を引き受け済み。
B. 来月の紹介文を書く。締切は7月1日17:00。所要時間90分。
   自分が担当を引き受け済み。
C. 共有メモにある見積内容の照会。締切は6月11日15:00。所要時間45分。
   先方の返答を受けてから次の人が作業する。まだ担当はいない。
D. 提出物の確認依頼。本文に「なるべく早く」とあるだけ。所要時間も不明。

全部のタスクを残したうえで、今日の「まず一つ」「その次」「待ち」「相談」を提案してください。
担当未定や期限不明の項目について、誰に何を確認する必要があるかも示してください。
```

## 確認すること

- Aを11:30までに処理する具体的な時間を確保し、固定予定との衝突を避ける。
- Cは明日の不在と後続作業を踏まえて今日の調整対象にし、引受候補と担当確定を区別する。
- Dの「なるべく早く」を架空の締切に置き換えず、期限・影響・作業内容を確認する。
- Bを消さずに残し、AやCの対応を押し出して最優先にしない。
- 連絡や担当決定を行ったふりをしない。

具体的な並べ方は複数あり得ます。確認すべき点が明示され、実行できる計画になっているかを見ます。

## 学生生活・家庭での置き換え

- 学生生活なら「出欠人数」を「授業のグループ発表の参加確認」に置き換えます。試験や授業の固定予定も渡します。
- 家庭なら「見積照会」を「修理訪問の日程確認」に置き換えます。家族に担当をお願いするときも、引受の返事を確認します。

性別や職業で困りやすさを決めつけず、自分が困っている場面に合わせてください。
