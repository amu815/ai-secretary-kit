# はじめてのAI秘書キット

仕事・学業・家庭の用事を「集める → 順番を決める → 進める → 確認する」ための日本語スターターキットです。優先順位、メールの読み落とし、自然な日本語、引き継ぎを、繰り返し使える手順にします。

**最初はプログラミング不要。** ChatGPTに指示文と架空のサンプルを貼り付けるだけで試せます。メールの自動送信や、実際の受信箱との接続は行いません。

## まず使う

1. [はじめ方](docs/quickstart.md)でChatGPTの利用環境を確認する。
2. [AI秘書への共通指示](prompts/secretary-instructions.md)をコピーする。
3. [架空の練習例](examples/first-day.md)を入力し、回答を元の依頼と照合する。
4. [毎日の使い方](docs/daily-workflow.md)に沿って、自分に合う運用にする。

GitHubを使い慣れていない方は、上のリンクを開いて本文をコピーしてください。一括保存する場合は、このページの **Code → Download ZIP** を選びます。

## 何を助けるか

| 困りごと | キットで行うこと |
| --- | --- |
| 何から始めるか迷う | 締切・影響・所要時間・相手の待ち時間から、次の一手を提案 |
| メールの一部を見落とす | 依頼・質問・期限・必要な添付を一つずつ抽出 |
| 返信の言い回しに自信がない | 意味を変えず、相手との関係に合う日本語へ修正 |
| 不在中に仕事が止まる | 期限・未完了事項・引き受け確認まで含む引き継ぎを作成 |
| 共有の仕事の担当が曖昧 | 担当候補と担当確定を分け、引受を確認 |
| AIの文をそのまま送りそう | 下書き・確認事項・人の確認を分ける |

本キットは個人の能力や属性を評価するものではありません。業務量、期限の曖昧さ、相談経路、分担の仕方も一緒に見直すために使います。

## 選べる導入方法

| 方法 | 向いている人 | 手順 |
| --- | --- | --- |
| ChatGPTにコピー＆ペースト | 最初に試したい人 | [クイックスタート](docs/quickstart.md) |
| dotsに日々の整理を依頼 | 利用資格と画面上のアクセスがある人 | [dotsの設定](docs/dots-setup.md) |
| Codexなどにskillsを追加 | 手順を繰り返し呼び出したい人 | [skillsの導入](docs/install-skills.md) |
| ローカルの送信前確認ツール | コマンド操作ができる人 | [review gate](docs/review-gate.md) |

ChatGPT Plusを使った導入を基本にしています。ただし、**Plus契約だけでdotsが使えるわけではありません**。2026-10-22に確認した公式案内では、dotsは対象のPro・Business Premium・Enterpriseで段階展開中です。課金前に[現行の料金](https://learn.chatgpt.com/docs/pricing)と[dotsの利用条件](https://learn.chatgpt.com/docs/dots#access)を確認してください。APIキーはこのキットに不要です。

## 実際に防げること・人が確認すること

プロンプトやskillsはAIの動作を導く指示です。誤読や誤送信を技術的に完全防止するものではありません。基本運用では送信手段を接続せず、人が自分のメールソフトで宛先・本文・添付を確認して送信します。

任意の確認ツールは、確認した宛先・本文と一致するデータだけをテキストに書き出します。メールソフトの送信ボタンを制御する機能はありません。

公開リポジトリに保存するのは教材のみです。実メール、個人情報、業務データは登録しないでください。AIに入力できる情報の範囲は、所属先のルールに従ってください。
