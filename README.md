# はじめてのAI秘書キット

仕事・学業・家庭の用事を「集める → 順番を決める → 進める → 確認する」ための日本語スターターキットです。優先順位、メールの読み落とし、自然な日本語、引き継ぎを、繰り返し使える手順にします。

**最初はプログラミング不要。** はじめるための文をChatGPTアプリへそのまま送ると、番号や短い言葉で答えられる質問を一つずつ出すようにしています。先に入力フォームを埋める必要はありません。メールやカレンダーを連携せずに始められます。

## まず使う

**[Webガイド「はじめてのAI秘書」を開く](https://ai-secretary-kit-amu815.easytoast2050.chatgpt.site)** → はじめるための文をコピー → ChatGPTアプリの新しいチャットへそのまま貼り付けて送信 → 質問に番号などで一つずつ答えます。GitHubの登録・操作や、サイト教材のインストールは不要です。ChatGPTアプリの導入とログインは必要です。[PCアプリの公式導入手順](https://learn.chatgpt.com/docs/quickstart?setup=app)

PCではWebガイドの「ChatGPTアプリを開く」から起動を試せます。スマホ、またはボタンで開かない場合は、ChatGPTのアプリアイコンから開いてください。場面別の文と、送信前チェックもそのまま使えます。

役割や使う場面、AIへの慣れ具合は、答えたい範囲だけ伝えます。実名や所属は不要で、「スキップ」も選べます。すでに予定やメールを渡している場合は、その整理から進めます。

文章で読みたい方は、[3ステップのはじめ方](docs/quickstart.md)にも、そのまま送れる導入文を載せています。初回にProjectsやskillsを設定する必要はありません。

日常の用事は、**全体の仕事リストを貼る・スクリーンショットを渡す・用事を1件だけ話す**のいずれかから始めます。不足は会話で一つずつ補い、終わりたいときは「今日はここまで」と伝えます。

普段の予定に使い始めたら、[毎日の使い方](docs/daily-workflow.md)を参照してください。教材をダウンロードして改良したい方は **Code → Download ZIP** で一括保存できます。

コピーが負担になってから、必要に応じて[Gmail・Google Calendarの連携手順](docs/setup-connections.md)を検討してください。連携の設定、アクセス権限、常時監視は別のものです。許可画面を確認して操作するのは本人で、基本は読み取りと下書き、人による送信です。

## 何を助けるか

| 困りごと | キットで行うこと |
| --- | --- |
| 何から始めるか迷う | 締切・影響・所要時間・相手の待ち時間から、次の一手を提案 |
| メールの一部を見落とす | 依頼・質問・期限・必要な添付を一つずつ抽出 |
| 返信の言い回しに自信がない | 意味を変えず、相手との関係に合う日本語へ修正 |
| 不在中に仕事が止まる | 期限・未完了事項・引き受け確認まで含む引き継ぎを作成 |
| 共有の仕事の担当が曖昧 | 担当候補と担当確定を分け、引受を確認 |
| AIの文をそのまま送りそう | 下書き・確認事項・人の確認を分ける |

本キットは個人の能力や属性を評価するものではありません。業務量、期限の曖昧さ、相談経路、分担の仕方も一緒に見直すために使います。

## 選べる導入方法

| 方法 | 向いている人 | 手順 |
| --- | --- | --- |
| ChatGPTアプリにコピー＆ペースト | 最初に試したい人 | [Webガイド](https://ai-secretary-kit-amu815.easytoast2050.chatgpt.site)・[文章の手順](docs/quickstart.md) |

## 実際に防げること・人が確認すること

プロンプトやskillsはAIの動作を導く指示です。誤読や誤送信を技術的に完全防止するものではありません。基本運用では送信手段を接続せず、人が自分のメールソフトで宛先・本文・添付を確認して送信します。

任意の確認ツールは、確認した宛先・本文と一致するデータだけをテキストに書き出します。メールソフトの送信ボタンを制御する機能はありません。

公開リポジトリに保存するのは教材のみです。実メール、個人情報、業務データは登録しないでください。AIに入力できる情報の範囲は、所属先のルールに従ってください。
