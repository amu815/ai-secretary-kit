# 人が行う送信前チェック

AIの下書きを読んだあと、実際に送信するメールソフト上でも確認します。

- [ ] To・Cc・Bccは正しい。返信先や共有してよい相手を原文と照合した。
- [ ] 原文の依頼・質問に答えている。氏名・数字・日時・タイムゾーン・約束・承認の有無を根拠と照合した。
- [ ] 相手との関係に合う表現で、自分の意図と一致している。AIの注釈や未記入欄が本文に混ざっていない。
- [ ] 必要な添付を実際に開き、内容・版・送信先への開示範囲を確認した。リンクは相手が閲覧できる。
- [ ] 要確認事項が解消している。最後に編集した後の宛先・本文・添付を読み直した。

どれかを確認できない場合は、下書きに戻します。AIにチェック欄を埋めさせるだけでは人の確認になりません。
